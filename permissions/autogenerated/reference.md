## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-list-readers`
- `allow-connect-reader`
- `allow-scan-card`
- `allow-cancel-scan`
- `allow-disconnect-reader`
- `allow-read-blocks`
- `allow-poll-card`
- `allow-release-card`
- `allow-request-service`
- `allow-search-services`
- `allow-select-system`
