# 対応ハードウェアと環境

本プラグインは、Sony 製の非接触 IC カードリーダー／ライター「PaSoRi（パソリ）」シリーズに幅広く対応しています。

---

## 対応リーダー一覧

| モデル名 | チップセット / ファミリ | 主な用途・特徴 | 状態 |
| :-- | :-- | :-- | :-- |
| **RC-S380** | NFC Port-100 | 現行の定番モデル。高速かつ安定した通信が可能 | **完全対応** |
| **RC-S300** | NFC Port-400 | 最新の小型・現行モデル。WinUSB / CCID / PC/SC 対応 | **完全対応** |
| **RC-S330** | RC-S956 | 前世代の普及モデル（e-Tax等で広く利用） | **対応** |
| **RC-S360** | RC-S956 | 内蔵型 / 業務向けバリエーション | **対応** |
| **RC-S370** | RC-S956 | 業務向け・特定用途向けバリエーション | **対応** |
| **RC-S320** | RC-S320 | 初期型 PaSoRi（USB 1.1 世代） | **対応** |

---

## ハードウェア仕様詳細

### 1. RC-S380 (Port-100)

- **ベンダーID (VID)**: `0x054C` (Sony)
- **チップセット**: NFC Port-100
- **特徴**: バルク転送を用いた高速通信。ドライバの相性問題が最も少なく、推奨されるリーダーです。

### 2. RC-S300 (Port-400)

- **ベンダーID (VID)**: `0x054C` (Sony)
- **チップセット**: NFC Port-400
- **特徴**: Windows 標準のスマートカード (CCID) プロトコルおよび WinUSB に対応した現行機種です。

### 3. RC-S330 / RC-S360 / RC-S370 (RC-S956)

- **ベンダーID (VID)**: `0x054C` (Sony)
- **チップセット**: RC-S956
- **特徴**: 専用のフレームヘッダ（ACK/NAK ハンドシェイク）を伴うシリアルUSB通信を行います。

### 4. RC-S320

- **ベンダーID (VID)**: `0x054C` (Sony)
- **チップセット**: RC-S320
- **特徴**: 初期のパソリ製品。通信速度やバッファサイズに制約がありますが、本プラグインでは適切なタイミング制御により動作をサポートしています。

## リーダーの指定と優先度設定

PC に複数の PaSoRi リーダーが接続されている場合、明示的に接続先を指定したり、接続優先度を設定したりできます。

### ID による明示的接続

`FelicaReader.list()` で取得した `ReaderInfo` の `id` を指定して接続します。

```typescript
const readers = await FelicaReader.list();

// 特定のリーダー (例: RC-S380) を探して接続
const s380 = readers.find((r) => r.productId === 0x06c3);
if (s380) {
  const reader = await FelicaReader.connect({ id: s380.id });
}
```

### 優先度オプション (`preference`)

ID を指定しない場合、`preference` オプションによって優先するリーダー種別を指定できます。

| 指定値 | 説明 |
| :-- | :-- |
| `"auto"` (既定) | 最も安定性の高いリーダー（RC-S380 → RC-S300 → RC-S330 → RC-S320）を自動選択 |
| `"rc_s380"` | RC-S380 ファミリを優先 |
| `"rc_s300"` | RC-S300 ファミリを優先 |
| `"rc_s330"` | RC-S330 / 360 / 370 ファミリを優先 |
| `"rc_s320"` | RC-S320 を優先 |

```typescript
// RC-S300 を優先して接続
const reader = await FelicaReader.connect({
  preference: "rc_s300",
});
```
