# Agent Instructions (example app)

This package is the plugin host app under `examples/`. It exercises `FelicaReader.scan()` which returns a `ScanResult`. Client-side parse helpers are not used.

## Quality gates

Changes must pass with **no warnings and no errors**:

- `pnpm lint` (`vp lint`; do not use npm, yarn, or bun)
- `cargo check` in `src-tauri`

## Comments

Write all code comments in English.

## Design principles

- Separate concerns and keep the blast radius of a change small.
- Keep high cohesion so internals can change without spreading edits.
- Keep coupling loose and minimize dependencies.
- Abstract at stable boundaries so the code tolerates change.
- Remove redundancy; do not duplicate logic.
- Do not over-nest directories. Keep the layout easy to follow.

## Tooling

Use **pnpm** as the only JavaScript package manager and script runner in this package, matching official Tauri plugin examples. Do **not** use npm, yarn, or bun.

- Pin the manager with top-level `packageManager` (`pnpm@10.18.0`); do **not** use `devEngines` for this
- Install from this directory: `pnpm install` (or `vp install`)
- Depend on the plugin API with `"tauri-plugin-felica-api": "file:.."` (create-tauri-plugin template). The root `package.json` already exports `dist-js/`; do not add a second package.json under `dist-js/`
- Scripts: `pnpm dev`, `pnpm build`, `pnpm preview`, `pnpm lint`, `pnpm tauri`

Use **Vite+** for the frontend (invoked through pnpm scripts, or `pnpm exec vp` if you must call the CLI directly):

- `vp dev`, `vp build`, `vp preview`, `vp lint`
- Tailwind CSS v4 via `@tailwindcss/vite` and `@import "tailwindcss"`
- Tailwind class linting via `oxlint-tailwindcss` in `vite.config.ts` (`lint` block)
- Routing via TanStack Router (file-based routes in `src/routes/`)

Use **cargo** for the host crate in `src-tauri`.

Do not replace Vite+ with a standalone Vite + Oxlint split in this package. The plugin crate at the repository root uses **bun** and cargo; this example uses **pnpm**. See [../AGENTS.md](../AGENTS.md).

## Architecture

```
src/main.tsx        Router bootstrap
src/routes/         File-based routes (`/` scan, `/lab` low-level)
src/features/       Scan UI
src-tauri/          Tauri host; registers `tauri_plugin_felica::init()`
```

- The `/` route hosts the reader scan screen (`ScanResult` products, not client parse).
- `/lab` is a low-level console (poll / requestService / read / selectSystem / searchServices / release). Do not add a bulk dump button.
- `src/routeTree.gen.ts` is generated by TanStack Router; do not edit it by hand.
